# Story 1.2: Private visit page

## Status

Ready for Review

## Story

**As a patient,**
**I want** a private link for my visit,
**so that** I can follow it without creating an account.

## Acceptance Criteria

1. Each appointment gets its own link that cannot be guessed from another patient's link.
2. The page shows the patient's first name, the appointment date and time, the professional's name and the clinic address.
3. The page never shows another patient's name, time or details.
4. The link works from 3 hours before to 3 hours after the appointment. Before that, it shows only the time it opens; after, it shows "This visit has ended".
5. Opening the link needs no login, password or app.

### Completion Notes List

- Visit links are HMAC-derived tokens; only their SHA-256 hash is stored (ADR-004). The window is 3 hours before to 3 hours after the appointment.
- Opening the link sets a device cookie that WR-07 uses to recognise the phone.
- Tests run against a local Postgres 16 (one database per test file) instead of Testcontainers, because the development container has no Docker.
- All time comes from server/clock.ts; `npm run lint` fails on direct use of the system clock.
- Tests for this story:
  - `app/test/integration/patient.test.ts` › WR-02: T-08 the link shows "opens at 11:00" at 10:59, is live from 11:00 to 17:00, and has ended at 17:01
