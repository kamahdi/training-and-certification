# Story 1.1: Import appointments from the demo file

## Status

Ready for Review

## Story

**As a receptionist,**
**I want** to load the day's appointments from a file,
**so that** every patient gets a visit page without anyone retyping them.

## Acceptance Criteria

1. The file is a CSV with the columns: patient name, phone number, professional, date, time.
2. Given a file of valid rows, when it is uploaded, then each row becomes an appointment and the screen shows how many were imported.
3. Given a row with a missing field or an invalid phone number, then that row is skipped and listed with its row number and the reason.
4. Belgian numbers are stored in international format: 0470 12 34 56 becomes +32 470 12 34 56.
5. Uploading the same file twice creates no duplicates. The same phone, professional, date and time count as one appointment.

- Reception uploads the CSV on the reception screen; the import result lists imported, updated, cancelled and refused rows with row number and reason.

- Tests run against a local Postgres 16 (one database per test file) instead of Testcontainers, because the development container has no Docker.
- All time comes from server/clock.ts; `npm run lint` fails on direct use of the system clock.
